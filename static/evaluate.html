Chunking

RQ1 — how document splitting affects retrieval- vs. generation-layer metrics.
Fixed-size packs raw text into token windows. Sentence and recursive respect sentence/paragraph boundaries. Semantic embeds each sentence and cuts wherever adjacent sentences stop being similar — slower to build, since it requires an embedding pass per document.

Embedding

RQ2 — embedding model choice vs. retrieval-layer metrics.

Retrieval & fusion

Retrieval mode is a technique axis (dense / sparse / hybrid / diversity-aware); Top-K is retrieval depth; dense/sparse weights tilt hybrid fusion toward meaning vs. exact tokens.
Dense/sparse only ignore the other signal entirely. Hybrid modes combine both (RRF fuses by rank position; weighted fuses by normalized score margin). MMR reranks the dense candidate pool to trade relevance for diversity — λ=1 is plain dense ranking, λ=0 maximizes diversity.

Generator LLM

RQ3 — generator choice vs. faithfulness/accuracy, holding retrieval fixed. Free HuggingFace models and paid OpenRouter models can be benchmarked side by side.
⚠ This is a paid OpenRouter model — every question in this run (and every value in a sweep) makes a real, billed API call. Check pricing at openrouter.ai/models before running large question sets or sweeps.
